# 豪哥的手机 · 中文体验

基于用户指定的 https://gnrn.vercel.app/ 前端制作的中文个人体验版。原图、视频与剧情归原作者；原始 bundle 保存在 `assets/source.js` 以便核对。没有使用原目录里其它故事的照片或覆盖原文件。

## 使用

安装开发依赖后运行 `npm run build`，用静态 HTTP 服务打开 `dist/`。构建产物不需要后端，聊天、登录提示、电话和购物均为本地模拟。进度保存在当前浏览器的 `hao_phone_cn_v1` 中。

## 汉化与功能

- 858 条不同韩文字符串逐条翻译，时间和金额保留原值，韩元明确标注。
- 张家豪是姓名，豪哥是昵称；Kim Geonwoo 统一为金建佑。缺乏可靠汉字的个别配角保留音译。
- 同步翻译剧情触发词和对象键，支持用“别走”触发来电；所有攻略默认折叠。
- 开放原站已有但入口禁用的日历、GoodNotes 和外卖；用原站 17 张图片补充相册浏览、翻页和放大。
- 修复 KREAM 分类筛选、查看更多和穿搭标签，保留原站尚无内容的空状态。
- 媒体文件本地保存。原站缺失的 `gn2.jpg` 使用明确占位图，缺失的 `kong.jpg` 后备图改用同一人物原站头像。

`build.mjs` 使用 Acorn 解析字符串再替换，避免误改业务代码；构建会校验所有韩文文本有译文并再次解析生成的 JavaScript。`patches.mjs` 中的功能修复均要求精确匹配，源站升级时会显式报错。
